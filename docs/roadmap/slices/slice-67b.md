## Slice 67B: Debug Text Migration, Event Log, Text Atlas Telemetry, And UI Sound Cues

> [Roadmap index](../../framework-implementation-slices.md) · Depends on: [Slice 53A](slice-53a.md), [Slice 53B](slice-53b.md), [Slice 44](slice-44.md) · Track: [VoidLight port](../tracks/voidlight-port.md)

**Status: not started.** Independent of 67A and 67C.

Goal:
- The last surface-text consumers (FPS counter, AI debug overlay) move onto
  `TextLabelSystem`, and the `PreparedText` / `TTF_RenderText_Blended`
  path is deleted, so the app has one text pipeline.
- The demo HUD gains a fixed-size, typed event log fed from each step's
  simulation events, read-only and presentation-only.
- Atlas page pressure becomes measurable (perf counters and a gpu-smoke
  Western-corpus probe), with a recorded number behind 53A's page cap.
- UI navigation plays short fixed cues through stable `AudioAssetId`s that
  survive the pause SFX stop.

### Current foundation

- `src/render/fps_counter.zig` composes a prefix and per-digit
  `PreparedText`s in drawable space, reloading its font per DPI;
  `src/render/debug_overlay.zig` owns it and the F2 toggle, mirrored by
  `debug_overlay_stub.zig`.
- `src/game/ai_debug_overlay.zig` prepares behavior, tier, and digit
  `PreparedText`s per color, draws a drawable-space HUD block and
  world-space behavior labels, and bounds commands at one sprite per label.
  Its tier block hard-codes today's tier names (`dormant` … `cognition`).
- `src/render/text.zig`: after 53A/53B migrate the menus, the
  `PreparedText` / `TextCacheKey` / `TextEntrySlot` / `TextBackend` /
  `FontId` path has no consumer but these two overlays.
  `Renderer.drawablePixelScale` is used only by them.
- `src/game/simulation.zig` `SimulationEventPayload` has 10 arms; the only
  player-facing one today is `destructible_destroyed`. `GameDemoState.update`
  ends after the commit seam, when the step's merged events are complete.
- `src/app/audio.zig`: `PlaySfxRequest`, the per-step `AudioCommandBuffer`,
  and `setPaused` → `stopAllSfx`, which stops every SFX track on pause enter
  and exit (a resume confirm cue would be cut).
- SDL_ttf 3.2.2 packs each atlas page with a skyline packer and 1 px glyph
  padding.
- From 53A: label pool, page registry and cap, logical-space draws; from
  53B: HUD screen, theme, single focus setter; from 44: capture conflict
  rejection.

### Architecture notes

- Debug overlays and the event log are read-only over simulation; the log
  reads a finished step's merged events in canonical order, so its content
  is deterministic and never feeds back (`.claude/rules/engine-design.md`,
  `.claude/rules/simulation.md` § Events).
- The log shows the player's world: its scan costs the events that world
  emitted this step, never the number of worlds or far-simulated agents
  elsewhere (`.claude/rules/engine-design.md` § Target scale).
- The event log is a presentation-only fixed pool with deterministic drop
  and a counted overflow (`.claude/rules/budgets-capacities.md`); it holds
  only displayable rows, no history.
- Every `SimulationEventPayload` arm gets a compile-time decision (a line or
  explicit none) with no catch-all, so each later slice that adds an arm
  decides its line in its own change.
- The AI overlay's tier block follows the live tier set (Slice 75 redefines
  tiers as fidelity levels) rather than a hard-coded list, and never labels
  a far agent as stopped (`.claude/rules/simulation.md` § Scope and tiers).
- Debug text follows the presentation scale and UI scale like all UI text
  (a documented size change from window pixel density).
- The atlas page cap and atlas size never change; if the probe exceeds its
  slack, shipped title sizes shrink to a floor and the measured result is
  recorded (`.claude/rules/render.md` § Text).
- UI cues go through `AudioCommandBuffer` with stable IDs on a UI channel
  that pause does not stop; a full command buffer drops the cue with a
  count and never fails a state update (`.claude/rules/assets-audio.md`).
  Cue WAVs are generated by a committed deterministic stdlib tool.
- Main thread; draws, log pushes, and cue flushes are allocation-free after
  warmup; label creates stay 53A's cold path.
- VoidLight reference: `UIManager` event log (`UIManager.cpp:480-493`,
  `:1142-1166`) and combat/social log lines as typed-event feed arms; not
  controllers writing to the UI directly, string entries, or per-size font
  reloads.
